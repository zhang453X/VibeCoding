# 二维码宣传页编辑器

一个基于 React + Vite 的前端原型项目，用于编辑和预览“扫码宣传页”内容。页面采用典型的三栏编辑器布局：

- 左侧：模块列表与页面设置
- 中间：当前模块的编辑面板
- 右侧：手机端实时预览与二维码展示

当前项目更偏向高保真交互原型，适合用于演示扫码落地页的编辑流程、模块组合方式和视觉效果。

## 项目简介

这个项目主要实现了一个扫码宣传页编辑器，支持对宣传页内容进行模块化配置，并同步查看移动端预览效果。

已包含的核心能力：

- 页面标题、主题色、短链 Slug、分享描述等页面设置
- 模块的新增、删除、排序、显隐切换
- 品牌头图、企业文化、图片画廊、视频、商品故事、联系方式、客户评价、行动召唤等内容模块
- 素材库弹窗选择图片、视频和文案类内容
- 二维码展示区域与发布提示交互

## 技术栈

- 前端框架：React 18
- 构建工具：Vite 6
- 样式方案：Tailwind CSS v4 + 自定义主题变量
- UI 能力：Radix UI、Lucide React、MUI、Sonner、Recharts 等
- 语言：TypeScript + TSX

## 页面框架说明

项目当前是单页应用，没有引入实际的业务路由，主要界面结构如下：

1. 顶部工具栏
   - 展示页面标题、预览、分享、保存发布等操作
2. 左侧边栏
   - 在“模块”和“页面设置”之间切换
   - 用于管理模块顺序、显隐状态和基础配置
3. 中间编辑区
   - 根据当前选中的模块，显示对应编辑表单
4. 右侧预览区
   - 模拟手机端展示效果
   - 支持实时查看扫码宣传页最终呈现内容
5. 底部二维码区域
   - 展示二维码视觉效果
   - 模拟 Logo 嵌入和二维码下载入口

## 本地启动

### 环境要求

建议使用以下环境：

- Node.js 18 及以上
- npm 9 及以上

### 安装依赖

```bash
npm install
```

### 启动开发环境

```bash
npm run dev
```

启动后通常可在本地访问：

```text
http://localhost:5173
```

## 构建项目

生成生产环境构建文件：

```bash
npm run build
```

构建产物会输出到 `dist/` 目录。

## 可用脚本

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动本地开发服务 |
| `npm run build` | 执行生产构建 |

## 当前项目特点

- 当前为前端原型项目，未接入后端服务或真实接口
- 素材库中的图片、视频与文案数据为内置 mock 数据
- 主要业务逻辑集中在 `src/app/App.tsx`
- 适合先用于原型演示，后续再逐步拆分模块与接入真实数据源

## 后续优化建议

如果后续继续迭代，建议优先考虑：

- 将 `App.tsx` 中的大体量逻辑拆分为模块编辑器、预览组件、类型定义和 mock 数据文件
- 增加 ESLint / Prettier 等工程化配置
- 接入真实上传、保存、发布和二维码生成能力
- 补充页面截图、演示 GIF 或在线预览地址，方便放到 GitHub 展示
